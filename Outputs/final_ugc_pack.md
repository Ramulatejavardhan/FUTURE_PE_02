# 5. Platform Adaptations

## Instagram Reels Version

### Best Style
- Fast cuts
- Trending soft audio.
- Natural selfie camera.
- On-screen captions.
- Before/after transitions within first 3 seconds.

### Recommended Structure
- 0–3 sec → Hook
- 3–15 sec → Problem + salon experience
- 15–25 sec → Transformation reveal
- 25–30 sec → CTA

### Editing Tips
- Use close-up beauty shots.
- Include authentic reactions.
- Keep pauses and small imperfections.
- Avoid overly polished commercial feel.

---

## YouTube Shorts Version

### Best Style
- Slightly slower pacing than Reels.
- More storytelling.
- Voiceover works better.
- Add mini review/testimonial angle.

### Recommended Structure
- Immediate relatable problem.
- Quick journey/process clips.
- Final transformation + honest reaction.
- End with clear recommendation.

### Editing Tips
- Add subtitles throughout.
- Use natural salon sounds mixed with music.
- Show process clips longer than Instagram.
- Include lighting comparisons for hair/skin results.
