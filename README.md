# AI UGC Ad Generator

## Project Overview

This project demonstrates how AI prompt engineering can be used to generate UGC-style ad content for social media marketing campaigns.

The project focuses on creating authentic short-form ad scripts for Instagram Reels and YouTube Shorts.
